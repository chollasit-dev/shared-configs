# My Coding Style

Before determine which syntax version to use

- For non-project, standalone file, prefer newest syntaxes possible
- For project-based, check if
  - Targets an environment that supports new syntaxes
  - If language use transpiler, check if can convert new syntaxes down to target
    environment
  - If none is specified, use latest syntaxes

## Naming

- Check local file or file DB in project root, e.g., `db-naming.md`, etc.
  - Use good (prefer) one instead of bad
