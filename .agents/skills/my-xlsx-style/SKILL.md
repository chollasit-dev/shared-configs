# My XLSX Style

- Keep formula in each cell in its simpliest form
- Prevent syntaxes make it hard to read formula at first glance
  - No display logic: accounting, color, etc. Only keep basic formatting:
    general number, zero-trailing that make decimal aligned, etc.
  - No type conversion
  - No unnecessary IF, IFERROR unless ask
  - etc.

- Keep the sheet clean, consider every workbook meant for personal use or
  presentation with me explain each detail. So, unless asked to
  - Do not any text note

- Prefer working on a self-contained single sheet, no interlace or reference
  between sheets
