# Instructions

When writing in a standalone file environment, encourage using the new syntaxes
available

When editing inside a project, check whether

- The project already targets an environment that supports the new syntaxes
- The project has anything to transpile these new syntaxes down to the target
  environment. Avoid them if not
- If nothing is specified, use the latest syntaxes

## Encourage New Syntaxes

- Set Methods
- Iterator Helpers
- Promise.try
- Import Attributes
- Regular Expression Escape
- Array.fromAsync
- Error.isError
- Map Methods
- Math.sumPrecise
- Explicit Resource Management
- Temporal API
